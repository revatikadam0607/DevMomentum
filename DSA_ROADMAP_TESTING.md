# DSA Roadmap Manual Test Checklist

- [ ] Generate Beginner, Intermediate, and Advanced roadmaps.
- [ ] Change Academic Year (1st–4th Year) and verify topic priority changes.
- [ ] Change Branch and verify the branch context is used.
- [ ] Generate 4-, 8-, 12-, and 16-week roadmaps.
- [ ] Verify calendar tasks stay within the selected duration.
- [ ] Regenerate and verify the previous generated roadmap is replaced, not duplicated.
- [ ] Complete generated tasks, regenerate, and verify completed tasks remain completed.
- [ ] Leave Branch empty and verify generation is blocked.
- [ ] Enter empty, zero, negative, or invalid study hours and verify generation is blocked without hanging.
- [ ] Verify weekday and weekend hours are respected.
- [ ] Verify a roadmap requiring more hours than available shows a warning and does not create an incomplete roadmap.
